# 🐢 MoreHabit (모어해빗)
> **천천히, 하지만 확실하게 — 습관 & 뽀모도로 매니저 (PWA)**

마이루틴(MyRoutine) 서비스의 핵심적인 사용자 경험과 시그니처 기능을 벤치마킹하여, 유료 구독이나 서버 비용 없이 브라우저 로컬 저장소(LocalStorage)를 통해 즉시 사용할 수 있도록 제작된 반응형 모던 웹 애플리케이션입니다.

---

## ✨ 핵심 기능 요약

### 1. 루틴 추가 및 상세 관리
- **유연한 반복 주기 설정**:
  - `매일 반복`
  - `특정 요일 반복` (월, 화, 수, 목, 금, 토, 일 맞춤 선택)
  - `주 N회 반복` (주 1회 ~ 주 6회 목표 달성 카운트)
- **카테고리별 분류 및 컬러 태그**:
  - 운동 & 건강 🏃‍♂️ (세이지 그린), 공부 & 자기계발 📚 (인디고), 생활 & 습관 🌿 (틸), 마음 & 멘탈 🧘 (앰버), 취미 & 힐링 🎨 (로즈)
- **시간대 및 알림 시간 설정**:
  - 아침 / 낮 / 저녁 / 밤(취침 전) / 언제나 루틴 분류
  - 목표 시간(예: 07:30, 21:00) 설정 지원

### 2. 일일 체크리스트 및 실시간 달성률
- **7일 주간 날짜 스트립 (Date Strip)**:
  - 마이루틴 고유의 날짜 네비게이션: 오늘 바로가기, 이전/다음 주 이동
  - 날짜별 달성률 원형 게이지(Progress Ring) 실시간 표시
- **기분 좋은 스탬프 인터랙션**:
  - 원터치 체크 시 부드러운 도장(Stamp) 바운스 애니메이션
  - 100% 올클리어 시 화려한 컨페티(꽃가루 🎉) 축하 효과
- **실시간 달성률 게이지**:
  - 원형 Progress Ring 및 부드러운 프로그레스 바
  - 달성률에 따른 따뜻한 동기부여 코멘트

### 3. 회고 및 메모 (Daily Reflection & Notes)
- **개별 루틴 실천 메모**:
  - 루틴 체크 시 "오늘 스쿼트 50개 완료!", "마음에 드는 문장 필사" 등 메모 기록
  - 카드 내 말풍선 아이콘 및 메모 미리보기 제공
- **오늘의 하루 회고 (한 줄 일기 & 무드 피커)**:
  - 기분 이모지 선택 (🥰 최고, 😊 좋음, 🙂 보통, 🥱 피곤, 🌧️ 지침)
  - 오늘 하루에 대한 짧은 회고/감사 일기 작성 및 저장

### 4. 통계 및 기록 (히스토리 & 마이루틴 시그니처)
- **주간 신호등 매트릭스 (Weekly Traffic Light Matrix)**:
  - 각 루틴(행) × 요일(열) 신호등 보드
  - 한 주간의 루틴 실천 여부를 한눈에 조망 및 즉시 클릭 토글 가능
- **월간 달성 잔디 캘린더 (Monthly Grass Heatmap)**:
  - 날짜별 달성률(0% ~ 100%)에 따른 세련된 세이지/에메랄드 잔디 음영
  - 날짜 클릭 시 해당 일자의 루틴 내역과 하루 회고 바로 이동
- **연속 달성 스트릭 (Streak 🔥)**:
  - 전체 연속 실천 일수 및 루틴별 연속 실천 일수 랭킹
  - 챔피언 루틴 🏆 뱃지 표시

### 5. 완벽한 로컬 환경 & 데이터 보존 (무료 & 오프라인)
- **별도 유료 서버 및 회원가입 불필요**:
  - 모든 데이터는 사용자의 브라우저 LocalStorage에 안전하게 보관
- **데이터 백업 및 복원 (JSON)**:
  - 언제든 내 모든 루틴, 기록, 일기를 JSON 파일로 다운로드 백업
  - 새 기기나 브라우저에서 백업 JSON 파일을 불러와 1초 만에 복원
  - 샘플 데이터 다시 채우기 및 전체 초기화 기능 지원

## 🚀 실행 방법

### 로컬 개발 서버 실행
```bash
# 의존성 설치 (최초 1회)
npm install

# 개발 서버 실행
npm run dev
```
터미널에 표시되는 로컬 주소(예: `http://localhost:5173/`)를 브라우저로 열면 즉시 사용할 수 있습니다.

### 프로덕션 빌드
```bash
npm run build
```
빌드 결과물은 `dist/`에 생성됩니다. `main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 `dist/`를 GitHub Pages로 배포합니다.

캐릭터 이미지는 `public/mobit/`, 앱 아이콘은 `public/icon-192.png`·`icon-512.png`에 있습니다.
